# DM-12 Drum Machine

A drum machine that runs in your web browser. It's a single HTML file with no install, and every sound is generated live with the Web Audio API.

**Play it:** https://funkymiraculous.github.io/drum-machine/

## Features

- **12 pads:** kick, snare, rimshot, clap, closed and open hi-hat, three toms, crash, ride and cowbell. Play them by mouse, touch or keyboard (`Q`–`Y`, `A`–`H`).
- **10 preset beats:** Rock, Pop/Disco, House, Hip Hop, Funk, Reggae, Bossa Nova, Breakbeat, Techno and Latin.
- **Step sequencer:** 8, 16 or 32 steps, with accents and drag-to-paint.
- **Loop recorder:** play beats in live over a 1–8 bar loop, with:
  - quantise (none up to 1/32, including triplets) and a strength control
  - count-in and metronome
  - overdub or replace recording
  - undo, and hold-to-erase
  - the step beat playing underneath
  - sending a loop to the step sequencer
- **Global controls:** tempo with tap tempo, swing, master volume, and per-drum volume, mute and solo.
- **Saving:** save beats and loops by name in your browser.

## Run locally

Open `index.html` in any modern browser.
